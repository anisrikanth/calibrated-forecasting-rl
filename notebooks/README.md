# Notebooks

| Notebook | Purpose |
| --- | --- |
| `phase0_smoke_test.ipynb` | 20-step GRPO run on a toy urn-forecasting task with the project's output format and Brier reward; tests checkpoint and resume on Kaggle |
| `phase2_baselines.ipynb` | Base Llama 3.2 (no RL) on validation econ questions and held-out weather questions, with and without context; compared with the market price, base rates and always-0.5; ladder and bracket consistency; leak probe; reliability diagrams |
| `phase2b_prompt_ablation.ipynb` | Untrained 3B under prompts that reveal the key-numbers block one line at a time, plus an "estimate the number first" prompt; which part of the block raises discrimination (no training) |
| `phase3_grpo_train.ipynb` | GRPO training of a LoRA adapter on the econ training split (Brier or log-score reward plus format reward), checkpointing and resume, live hedging monitor, then untrained-vs-trained evaluation on the Phase 2 eval sets |
| `phase4_test_eval.ipynb` | The one evaluation on the untouched test split: loads each run's saved adapter (attached from its training version), checks each model reproduces its stored validation answers, then scores every model and baseline on the test questions and runs the comparisons fixed in `eval/test_plan.md` (no training) |

The Phase 2, 2b, 3 and 4 notebooks are generated by `build_notebooks.py` (`python notebooks/build_notebooks.py`), so edit the script, not the notebooks.

## Running on Kaggle

- **Accelerator: GPU T4 x2**, **Internet: On**.
- Add `data/processed/markets.csv` as a **private Kaggle dataset** and attach it with **Add Input → Your Work → Datasets**. It isn't in the repo (Kalshi's terms, and it's rebuilt by the pipeline). Upload a new dataset version whenever you rebuild it.
- The notebook clones this repo to use the tested `env/` code. If the repo is private, add a Kaggle secret named `GITHUB_TOKEN`.
- Use **Save Version → Save & Run All** so outputs are kept.

Notebooks are adapted from Unsloth's (LGPL-3.0).
